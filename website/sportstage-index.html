The ultimate cinematic 3D multi-sport platform for clubs, teams, and competitions. Experience sports like never before.

Powerful Features

Club Management

Create and manage sport-specific clubs, invite members, accept/reject requests, and maintain rosters with role-based access control. Server-controlled feature flags ensure secure operations.

Competitions & Matches

Schedule tournaments and leagues, manage fixture lists, and organize matches with support for singles and doubles formats across all supported sports.

MVP Calculations

Calculate comprehensive Match Value Points with batting, bowling, and fielding statistics. Six decimal places precision with detailed breakdowns.

Feature Flags

Server-controlled feature flags shipped disabled. Future mutations must use trusted server commands with read-only client grants and RLS-filtered access.
