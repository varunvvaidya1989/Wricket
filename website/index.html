About Wricket

Wricket is a comprehensive sports application platform built with Expo Router and React Native, designed to support multiple racket sports while maintaining a separate cricket domain. The platform provides end-to-end solutions for club management, competition scheduling, player statistics, and MVP calculations.

Built with strict TypeScript, the application follows modern development practices including Vitest testing, Expo ESLint configuration, and continuous integration with Node 20.

  • Multi-sport: Tennis, Badminton, Padel, Table Tennis, Pickleball
  • Cricket domain with separate database model
  • Club and team management with member invitations
  • Sport-specific scoring engine
  • MVP calculation system
  • Row-level security with Supabase
  • Web export for desktop access
